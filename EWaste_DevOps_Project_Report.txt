1. ABSTRACT
The E-Waste Management System is a web application for managing electronic waste collection requests. This project demonstrates DevOps practices such as version control, continuous integration, containerization, deployment, and monitoring.

2. OBJECTIVES
- Maintain source code using Git and GitHub.
- Automate testing using GitHub Actions.
- Package and run the backend using Docker.
- Deploy the application using Render.
- Monitor application health using Prometheus and Grafana.

3. TECHNOLOGIES USED
- Python and FastAPI: Backend API
- SQLite: Database
- Git and GitHub: Version control
- GitHub Actions: Continuous integration
- pytest: Automated testing
- Docker: Containerization
- Render: Deployment
- Prometheus: Metrics collection
- Grafana: Monitoring dashboard

4. IMPLEMENTATION
The backend is located in the backend directory. The main application files include main.py, crud.py, database.py, and schemas.py.

The GitHub Actions workflow is stored in .github/workflows/ci.yml. It installs dependencies and runs the backend test suite.

The Dockerfile packages the backend and starts the FastAPI application using Uvicorn. The application was also deployed to Render.

5. MONITORING
The monitoring directory contains probe.py, Dockerfile, prometheus.yml, and blackbox.yml.

The custom Python probe checks whether the local EWaste API responds with the expected message. It exposes the ewaste_api_up metric. A successful metrics request returned ewaste_api_up 1.

Prometheus collects this metric, and Grafana displays it using a Stat visualization.

6. TESTING
Backend tests are executed with:
.\venv\Scripts\python.exe -m pytest .\tests\ -v
